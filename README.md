# 救急訓練シミュレーター（操作・評価版）

救急隊員の訓練用に、想定の付与・バイタル／心電図モニター表示・活動記録・評価を1つのHTMLで行うツールです。サーバー不要で、`index.html` をブラウザで開くだけで動きます。

## 主な機能

- **操作・活動記録画面**
  - モニター表示の切り替え（別ウィンドウのPCモニター、WebRTCで直接つなぐiPadモニター）
  - バイタルサイン（脈拍・SpO₂・血圧・体温・EtCO₂）と心電図リズムの操作
  - CPA確認・胸骨圧迫（比率・中断時間の自動計測）・心拍再開・病院到着の記録
  - 解析・除細動の操作
  - 活動記録（出場〜現場出発、観察・処置、病院連絡、特定行為）のクリック記録
- **想定票**：3症例（急性胆管炎によるショック／アルコール・睡眠薬服用による意識障害と低血糖／10歳男児のアナフィラキシー）。接触後の時間経過・処置に応じて状態が自動で変化します。想定票のA4印刷に対応。
- **分析・評価画面**：胸骨圧迫の質、主な時間、バイタル推移グラフ、時系列、活動の評価、結果テキストのコピー、評価シートのA4印刷。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Safari 推奨）で開く。
2. 必要なら「想定票」から症例を選ぶ。
3. 「モニターを開く」でモニター画面を開き（ポップアップを許可）、「想定開始」を押す。
4. 傷病者接触・CPA確認などをクリックで記録する。
5. 終了後は「想定終了」→「分析・評価」画面で確認・印刷する。

### iPadをモニターにする

**接続番号方式（通常）**：PCとiPadの両方をインターネットにつなぎます。

1. PCの操作画面でモニター表示の「iPad」ボタンを押すと、6桁の接続番号が表示されます。
2. iPadで同じURLを開き、「iPadをモニターにする」を押します。
3. 接続番号を入力して「接続」を押すと、iPadにモニターが表示されます。

アカウント登録は不要です。接続の取り次ぎに、無料の公開サービス（PeerJS Cloud）を使います。取り次ぎに使うのは接続の合図だけで、訓練データはPCとiPadの間を直接流れます。サービスが止まっている場合や回線がない場合は、下の予備方式を使ってください。

**予備：コード貼り付け方式**：インターネットなしで、同じWi-Fi内でつなぎます。「iPad」ボタンのダイアログにある「予備：コード貼り付け方式」を開き、PCの接続コードをiPadに、iPadの返信コードをPCに貼り付けます。

## GitHub Pages で公開する場合

リポジトリの Settings → Pages で、公開するブランチとフォルダ（`/ (root)` またはこのフォルダ）を指定してください。`.nojekyll` を同梱しています。

## 注意

- 記録内容はブラウザの localStorage に保存されます（端末内のみ）。
- フォント（Google Fonts）と、接続番号方式の部品（PeerJS）の読み込みにインターネット接続が必要です。未接続の場合は代替フォントで表示されます。
- 想定の薬剤・特定行為の内容と目標時間は訓練用の目安です。実際の運用は所属のMCプロトコール（沖縄県MC協議会プロトコル等）と指導者の方針に従ってください。
- 実在の傷病者情報は入力しないでください。
