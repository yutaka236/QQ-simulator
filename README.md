# 救急訓練シミュレーター（操作・評価版）

救急隊員向けの訓練用シミュレーターです。ブラウザだけで動作する単一のHTMLファイル（`index.html`）で、サーバーやインストールは不要です。

## 主な機能

- **操作・活動記録**
  - 主要時系列、病院連絡、観察・処置、特定行為のボタンで、現在時刻と活動開始からの経過時間を記録
  - CPA確認、心拍再開、病院到着の記録と、胸骨圧迫比率の測定
  - 解析・除細動、心電図波形の操作
  - バイタルサイン（脈拍・SpO₂・血圧・体温・EtCO₂）の設定とモニターへの反映
- **モニター表示**：PC／iPadの別画面に生体モニターを表示
- **想定票**：想定を選ぶと、処置に応じてバイタルが変化
- **分析・評価**：記録した時系列の確認、評価、印刷

## 使い方

1. `index.html` をブラウザ（Chrome / Safari / Edge 推奨）で開く
2. 「想定開始」で活動を開始し、各ボタンを押して記録する
3. 「分析・評価」タブで振り返る

訓練中の記録はブラウザ内（localStorage）に保存されます。サーバーには送信されません。

## GitHub Pagesで公開する場合

1. このフォルダの中身をリポジトリの直下に置いて push
2. リポジトリの **Settings → Pages** で、Source を `Deploy from a branch`、Branch を `main` / `(root)` に設定
3. 表示されたURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）で利用可能

## 注意

- 訓練・教育目的のシミュレーターです。実際の傷病者への対応や医療判断には使用しないでください。
- フォントを Google Fonts から読み込みます。オフライン時は標準フォントで表示されます。
- 個人情報・実在の傷病者の情報は入力しないでください。
